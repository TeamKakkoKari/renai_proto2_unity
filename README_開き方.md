# ことばを紡ぐ恋愛シミュレーション（プロトタイプ2）Unity版

Godot版「プロトタイプ2 v9」をUnityで開いて作業できるように移植したプロジェクトです。
**v10で助詞・接続語を利用した日本語文章解析システムを追加、v11で単語選択UIをカテゴリー別パレットに改修し、画像のテクスチャ設定をPoint (no filter)にしました。v12では好感度の引き継ぎ対策とテキスト表示の対策を行い、v13ではUIデザイン参考画像をもとに発言エリアとステータス表示を改良、v14では参考画像と同じ題材のアセットを新規生成し、画面構成そのものを参考画像のレイアウトに組み替えました**（下記参照）。

## リポジトリから開く方法（推奨・半自動の更新フロー）

このプロジェクトは GitHub リポジトリ（TeamKakkoKari/renai_proto2_unity、プライベート）で管理されています。開発側の更新はすべてここへ随時 push されるので、zip を受け取る必要はありません。

**初回のみ（詳しい手順）**

A. GitHub Desktop の準備
1. desktop.github.com から GitHub Desktop をダウンロードしてインストール
2. 起動したら「Sign in to GitHub.com」を選び、TeamKakkoKari のアカウントでサインイン（このリポジトリはプライベートなので、サインインしないと見えません）

B. リポジトリをクローン（複製）する
1. メニューの「File」→「Clone repository...」を開く
2. 「GitHub.com」タブで `TeamKakkoKari/renai_proto2_unity` を選択
3. 「Local path」に保存先フォルダを指定（例: ドキュメント\GitHub\renai_proto2_unity）
4. 「Clone」を押す（数十秒〜数分でダウンロード完了）
   ※ ブラウザでリポジトリページを開き、緑の「Code」→「Open with GitHub Desktop」でも同じことができます

C. Unity で開く
1. Unity Hub を開く（無ければ unity.com からインストール）
2. 「Open」の横の ▽ →「Add project from disk」で、クローンしたフォルダ（Assets や ProjectSettings が入っているフォルダそのもの）を選択
3. 推奨バージョンは **Unity 2022.3 LTS**。入っていない場合は Hub の「Installs」→「Install Editor」から 2022.3.x を追加してください（違うバージョンでも開けますが初回に変換が入ります）
4. プロジェクトを開く（初回は Library の自動生成で数分かかります）
5. 下部の Project ウィンドウで `Assets/Scenes/Main.unity` をダブルクリックしてシーンを開き、画面上部中央の ▶（再生）ボタンで実行
6. Game ビューの比率は 16:9（または 1280×720）にすると想定通りのレイアウトになります

**更新を受け取るとき（2回目以降）**
1. Unity の再生を止めておく
2. GitHub Desktop で左上の「Current Repository」が renai_proto2_unity になっていることを確認し、上部の「Fetch origin」を押す
3. 新しい更新があるとボタンが「Pull origin」に変わるので、それを押す
4. あとはいつも通り Unity Hub で開くだけ（変更分は自動で読み直されます）。左側の「History」タブで v14 などの版数も確認できます

※ こちら側でファイルを編集・保存していると Pull が止まることがあります。その場合は「Changes」タブでファイルを右クリック→「Discard Changes...（変更を破棄）」してから Pull してください。Unity のバージョン違いで ProjectVersion.txt が書き換わった場合も同じ操作で戻せます。基本は開いて再生するだけの使い方が安全です。

## 開き方（zipで受け取った場合）

1. Unity Hub を開く
2. 「プロジェクトを開く（Add / Open）」で、このフォルダ（renai_proto2_unity）を選択
3. 推奨バージョン: **Unity 2022.3 LTS**（それより新しいUnityでも開けますが、初回に変換が入ります）
4. 初回はインポートに少し時間がかかります
5. `Assets/Scenes/Main.unity` を開いて、上部の ▶（再生）ボタンで実行できます

※ 画面比率は 1280×720（16:9）想定です。Gameビューの比率を 16:9 にするとGodot版と同じ見た目になります。

### もし Main.unity が開けない場合

1. 空のシーンを新規作成
2. 空の GameObject を1つ作る
3. その GameObject に `Assets/Scripts/MainGame.cs` をアタッチして再生

（MainGame が Canvas や UI をすべて自動で組み立てるため、これだけでも動作します）

## 遊び方（Godot版と同じ）

- タイトル → マップで地域を選択 → 物語が始まります
- 質問の場面では、制限時間（60秒）以内にカテゴリータブから単語を選んで文章を組み立て、「発言する」を押します。選んだ単語はカードとして並び、カードを押すと取り消せます
- 文法（語順・助詞・語尾）・話題の合致・中身のある発言かどうかで好感度が変わります
- 助詞によって文章の意味と解釈が変わります（例:「あなたは好き」「あなたが好き」「あなたも好き」「あなたの好き」は別の文章として扱われます）
- 画面クリック / Enter / Space で文章送り、上部バー「ログ」でバックログ表示
- 好感度は自動保存されます（Unityの persistentDataPath 内 affection.json）

## データの編集（Godot版と同一形式）

`Assets/Resources/data/` のJSONを書き換えるだけで内容を変更できます。コードの変更は不要です。

- `words.json` … 単語（カテゴリ・タグ）
- `characters.json` … キャラ・質問・反応セリフ・表情差分
- `stories.json` … 物語の台本とエンディング
- `stages.json` … 地域（背景色・説明）
- `evaluation.json` … 評価の数値と制限時間

立ち絵・表情・ワールドマップ画像は `Assets/Resources/assets/`、フォントは `Assets/Resources/fonts/`（M PLUS Rounded 1c / SIL Open Font License）にあります。

## v14 の変更点（参考画像風アセット生成＋レイアウト組み替え）

- **新規アセット生成**: 参考画像と同じ題材で、森の遺跡の背景イラスト（エルフの森ステージ用）と、リーリアの新しい立ち絵イラストを生成しました。立ち絵は単色背景で生成し、プログラムで透過処理しています
- **画面構成を参考画像のレイアウトに変更**: 左上に吹き出し（名前・性格・セリフ）、右に「✏ あなたの発言」パネル、下に単語パレット、右下に「今回の評価」カードという配置になりました。従来の下部セリフ枠は廃止しています
- **ステータスはピル型表示**: 上部右に好感度と面白さのピル（数値＋バー）を配置。「📖 思い出」ボタンから会話履歴（バックログ）が開きます
- **信頼度の追加**: 好感度・面白さに加えて「信頼度」が貯まるようになりました（評価カードに表示、自動保存対応）。良い発言で少しずつ上がり、傷つける発言で下がります
- **単語検索**: パレット右上の検索欄に文字を入れると、全単語から部分一致で絞り込めます
- ※お試し版のため、背景イラストはエルフの森のみ、立ち絵はリーリアのみ差し替えです。リーリアの表情差分は今回の立ち絵には未対応（表情は変わらず笑顔の立ち絵のまま）で、他キャラクターは従来の立ち絵とステージ色背景のままです。評判が良ければ他キャラクター分も同じ画風で生成できます

## v13 の変更点（UIデザイン参考画像をもとに改良）

- **発言エリアの独立パネル化**: 質問の場面では「✏ あなたの発言」という見出し付きの専用パネルが開き、文章の組み立て場所が会話欄と明確に分かれるようになりました
- **選択中カードの操作**: 選んだ単語はカードとして並び、カード本体を押して選択（ハイライト）、右端の × で削除、◀▶ボタンで並べ替えができます。「↩ 一つ戻す」と「全解除」も同じ行にあります。発言ボタンは文章のすぐ右です
- **面白さの追加**: 好感度とは別に「面白さ」がキャラクターごとに貯まるようになりました（上部バーと、発言後の評価表示で別々に確認できます）。現実には難しい関係の発言（absurd）や聞き返しなど、好感度が低くても笑える発言で面白さが上がります。面白さも自動保存されます（旧セーブデータはそのまま読み込めます）
- **お気に入り単語**: 単語ボタンの右端の星（☆/★）でお気に入りに登録できます。パレットの「★ お気に入り」タブから、今回提示されていない単語も含めてすぐ選べます。「すべて」タブも追加しました
- 会話履歴は従来どおり上部バーの「ログ」からいつでも見られます

## v12 の変更点

- **好感度の引き継ぎ対策**: 好感度は自動保存されるため、一度マイナスに落ちると戻しにくい問題への対策です
  - マップ画面の右上に「好感度リセット」ボタンを追加（全キャラクターを0に戻せます）
  - 物語の始まり（地域への入場時と、物語が一周して最初に戻るとき）に、好感度がマイナスのキャラクターは時間経過で+10まで回復します（0が上限）
  - 好感度がすでにマイナスの相手へのマイナス評価は半分に緩和され、深掘りしにくくなりました
- **テキスト表示の対策**: 長い文章でも枠からはみ出さないよう、主なラベル（文章表示・セリフ・説明文・好感度表示・マップ説明）にフォントサイズの自動調整を入れました。文字の描画位置もピクセルに合いやすい設定（alignByGeometry）にしています
  - それでも特定の文字がぼやける場合は、Gameビューの解像度を 1280×720 または 1920×1080 に固定すると改善します（拡大率が中途半端だとUnityの仕様でぼやけます）

## v11 の変更点

- **単語パレットの分離・整理**: 文章を組み立てる場所を独立させ、単語は散らばさずカテゴリー別タブ（肯定/否定/感情/程度/対象/動作/接続/語尾）＋整列グリッドで提示します。選択中の文章は常に上部に表示され、選んだ単語はカードとして順番どおりに並びます。カードを押すとその単語を取り消せます。発言ボタンは文章のすぐ右にあります
- **画像のテクスチャ設定**: 全画像（立ち絵・表情・ワールドマップ）の Texture Type を Sprite (2D and UI)、Filter Mode を Point (no filter) に設定済みです（.meta で指定）。ドット感のあるシャープな表示になります。新しい画像を追加する場合も、Inspector で同じ設定にしてください

## v10 文章解析システム（助詞・接続語）

発言は `SentenceAnalyzer.cs` が助詞をもとに解析し、好感度の評価（Evaluator）とは**独立に**判定します。

- **助詞の役割**: は=話題、が=主語、を=動作の対象、に=受け手・方向、と=共同する相手、も=追加、の=所有・関係、で=場所・手段、へ=目的地、から=起点、まで=終点、や=並列。文末の「か/ですか」は質問、「してください」は依頼として扱います
- **関係の構築**: 「あなたと森へ行きたい」→ あなた（共同する相手）・森（目的地）のように、単語同士の関係を組み立てて意味を推測します
- **複数解釈の許容**: 「あなたが好き」「あなたの好き」のように複数の読み方ができる文は解釈候補を複数持ちます。好感度が高い相手の発言は好意的に解釈されやすく、決められない場合はキャラクターが聞き返します（専用セリフ「clarify」）
- **理解度Lv1〜4**: 1=自然、2=多少不自然だが推測可能、3=複数の解釈が可能、4=理解が困難。理解度と好感度は直接結びつけていません（不自然でも面白い文はあります）
- **現実には難しい関係**: 「リンゴと結婚してください」のような文は、失敗扱いではなく笑いの反応（専用セリフ「absurd」）になります
- 解析結果（関係・解釈・理解度）は、発言後に「ログ」で確認できます

単語は103語に増えました（助詞9種・文末表現6種・リンゴ/こと/結婚/あげる を追加）。助詞は質問の場面で常時提示されます。

## スクリプト構成

- `Assets/Scripts/MainGame.cs` … 画面・物語エンジン・UI（Godot版 main.gd の移植）
- `Assets/Scripts/Evaluator.cs` … 発言の評価ロジック（Godot版 evaluator.gd の移植。v10で助詞拡張と複数句の語順判定を追加）
- `Assets/Scripts/SentenceAnalyzer.cs` … v10追加。助詞による関係解析・解釈・理解度の判定
- `Assets/Scripts/JsonParser.cs` … 外部パッケージ不要でJSONを読むための小さなパーサ

## Godot版との違い

- マップ画面は、3Dモデルをリアルタイム表示する代わりに、真上から描いたワールドマップ画像＋地域ボタンで再現しています（見た目と操作は同等です）
- パネルの角丸など、装飾の一部は簡易再現です
- 検証について: 評価ロジックはGodot版と30ケースで出力（スコア・理由文まで）完全一致を確認済み（助詞拡張後も不変）。v10の解析システムは指定のテスト文12文＋文脈変更ケースで、関係・解釈・理解度・反応を検証済みです。C#コードのコンパイル確認も済んでいます（v14の改修後も確認済み）。ただしUnityエディタ自体での起動確認は未実施のため、初回再生時に問題があれば知らせてください。特定の場所の表示が気になる場合は、スクリーンショットを送ってもらえると正確に直せます
